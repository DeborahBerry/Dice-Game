# 🎲 Dice Game

A fun two-player dice game built using HTML, CSS, and JavaScript.
This project is designed to demonstrate interactive game mechanics and dynamic DOM manipulation.

## ✨ Features

- 🎲 Simulated dice rolling with images
- 🔁 Turn-based play for two players
- 💾 "Hold" option to save score
- 🏆 Win condition at 100 points
- 💡 Built without external libraries or frameworks

## 🔧 Technologies Used

- HTML
- CSS
- JavaScript (Vanilla)
  
## 🧠 How to Play

1. Two players take turns
2. On each turn, a player rolls the dice:
   - If the player rolls a `1`, they lose their turn and score
   - If the player rolls any other number, it is added to their current score
3. The player can choose to **Hold** to save their current score and pass the turn
4. The first player to reach **100 points** wins the game.
